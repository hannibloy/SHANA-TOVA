# 🌱 זורעים שנה - צידה לדרך (Seeds of the Year)

אפליקציית "זורעים שנה" היא מרחב דיגיטלי אינטראקטיבי המיועד לצוותי חינוך לקראת פתיחת שנת הלימודים. האפליקציה מזמינה את אנשי הצוות לעצירה, התבוננות פנימית ובחירת "עוגן" או כוח מוביל לשנה הקרובה, תוך שימוש בבינה מלאכותית (AI) ליצירת חותם ויזואלי אישי.

## 🧠 הרציונל הפדגוגי והפסיכולוגי
הפעילות נשענת על מודלים מובילים בפסיכולוגיה חיובית ובחוסן:
* **תאוריית התקווה של סניידר (Hope Theory):** חיזוק "כוח הרצון" (Agency) דרך בחירה אקטיבית של ערך מרכזי, וחיזוק "כוח הדרך" (Pathways) באמצעות דמיון והמשגת האופן שבו הערך יבוא לידי ביטוי במציאות החינוכית.
* **הון פסיכולוגי חיובי (PsyCap):** הזרעים שנבחרו (כגון אומץ, צמיחה, תקווה, לכידות) מהווים תשתית למסוגלות עצמית, אופטימיות וחוסן במרחב הבית-ספרי.

## 🚀 איך זה עובד?
1. **בחירת זרע:** המשתמש בוחר ערך/כוח שאותו ירצה להצמיח השנה.
2. **השקיה (Prompting):** המשתמש מתבקש לדמיין ולתאר כיצד ייראה הזרע הזה כשיפרח בסביבה החינוכית שלו.
3. **פריחה (AI Generation):** המערכת מתרגמת את החזון האישי של המשתמש לגלויה ויזואלית ייחודית בסגנון צבעי מים, באמצעות חיבור למחולל תמונות (Google API).

## 🛠️ טכנולוגיות
* HTML5, CSS3, JavaScript (Vanilla)
* אינטגרציה עתידית מול מחולל תמונות בבינה מלאכותית.
* פריסה (Deployment) באמצעות GitHub ו-Netlify.
